Urna eletrônica — voto para Presidente da República

Simulação em Python (via Pyodide, rodando no navegador) da tela de votação para Presidente, com os componentes descritos pelo TSE para 2026: barra de progresso, fonte Atkinson Hyperlegible, intérprete de Libras e teclado com braile. Candidatos e partidos são fictícios.

Cola para testar: números 37, 48, 61 ou 84 retornam um candidato fictício; qualquer outro número de 2 dígitos gera voto nulo. BRANCO exige o campo vazio.
